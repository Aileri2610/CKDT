# BER 

P_rx = P_ref·(d_ref/d)²            [W]
V_sig = R·P_rx·Rf  (≤ Vsat)       [V]   R: A/W
V_off = R·P_amb·Rf                 [V]
f3dB = 1/(2π·Rf·Cpd),  x = 2π·f_eff/bitrate
y_k = V_off + V_sig·(1−e^−x)·Σ_j e^(−jx)·b_(k−j)   (ISI)
σ² = Rf²·B·(4kT/Rf + 2q·I_bg + i_ex²),  B ≈ 1.57·f_eff
BER = ½·[Q((H−Vth)/σ) + Q((Vth−L)/σ)]  → Q(√SNR), SNR=(A_eff/2σ)²
Q(z) = ½·erfc(z/√2);  PRBS15: count TX≠RX bits
